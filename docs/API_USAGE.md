# Reddit API Usage

## Purpose

Job Hunter uses the Reddit API to read publicly available posts from a limited set of subreddits.

## Data Collected

* Post title
* Post URL
* Subreddit
* Timestamp
* Author username

## Data Retention

Metadata is cached for up to 30 days to prevent duplicate notifications.

## Restrictions

* No posting
* No commenting
* No voting
* No direct messaging
* No user profiling
* No redistribution of Reddit data
