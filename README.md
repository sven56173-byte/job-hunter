# Job Hunter

Job Hunter is a personal dashboard that helps discover publicly available freelance opportunities from selected Reddit communities.

## Features

* Reads new posts from selected public subreddits.
* Filters posts locally by keywords.
* Sends personal Telegram notifications.
* Stores only minimal metadata to prevent duplicate alerts.
* Read-only access to Reddit.

## Supported Communities

* r/forhire
* r/slavelabour
* r/webdevjobs
* r/freelance_forhire

## Privacy

This project is intended for personal, non-commercial use.

The application does not create posts, comments, votes, or direct messages. It only reads publicly available posts through the Reddit API and sends personal notifications to the owner.
